# wocyber.fpk

飞牛 wocyber 控制台 fpk 安装包归档仓库（S2 / A2 双型号）。

## 版本发布

各版本 fpk 安装包见 [Releases](https://github.com/zm51432/wocyber.fpk/releases)，资产统一命名为 `wocyber.fpk`：

| 版本 | 说明 |
|------|------|
| v1.3.32 | 偶数发布版，S2 / A2 双型号，确定性 MAC、主题重做、手机适配等 |
| v1.3.18 | S2 模组版本 |
| v1.3.12 | S2 模组初始版本 |

## 安装

下载对应版本的 `wocyber.fpk`，在 fnOS 应用中心安装即可。
